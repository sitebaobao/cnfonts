按场景选

  • 正文与长文阅读：思源黑体 / Noto Sans SC，9 档字重能拉开层级；宋体正文用思源宋体，标题用黑体。
  • 需要一套字体覆盖简繁混排：思源系与 Noto CJK 是同一套字形体系，简繁切换不用换字体；站酷小薇与霞鹜文楷只做点缀。
  • 标题、海报、落地页大字：霞鹜文楷（手写温度）或站酷小薇（展示味）。两者单字重，正文用它们会累。
  • 要"可变字重"调粗细：Noto Sans SC 与 HarmonyOS Sans 是可变字体，一个文件内插值，省文件数量。
  • App 与软件内嵌：HarmonyOS Sans 在软件内使用需在软件里显著声明（见下条），这是条款要求，不是建议。

三条硬规则（商用必做）

1. 以 LICENSE 原文为准，不认“免费商用”标签

OFL 1.1 的条款允许使用、修改、再分发，前提是字体文件本身不能单独出售。字体随软件、文档一起分发与销售是允许的。看到“免费商用”的宣传页，去仓库读条款原文再定。

2. 改字体要改名，保留名不可沿用

OFL 规定字体有"保留名字"（Reserved Font Name）。修改后的字体不得使用保留名字，衍生字体必须换名发布。改字重、改字形后继续叫原名，是违反条款的。

3. 自定义许可的字体的三条具体要求

HarmonyOS Sans 的许可写明：在软件中显著声明使用了 HarmonyOS Sans；不得修改字体本体；不得单独再分发或出售；须随副本保留版权声明与协议原文。用它做出的作品（设计稿、应用）可自由分发与出售，这条限制不作用于作品。

三个坑

  1. 中文全量字体拖慢网页：思源黑体全量 OTF 每个字重几十 MB，网页用 woff2 并按 unicode-range 分片加载，只取所需字符集。用 CSS font-display: swap 避免文字空窗。
  2. 字重插值不等于真字重：可变字体调出的 550、650 是插值，细笔画在小字号下发虚；正文关键层级用官方真实字重档。
  3. 授权链断在"字体包"上：市面"免费商用字体包"里混入方正、汉仪等有商业授权要求的字体，把包打包上线等于把授权问题一起上线。字体来源要能追到官方仓库。
