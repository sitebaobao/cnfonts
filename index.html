二、商用时的三条硬性规则

1. 字体文件不能单独卖。OFL 1.1 第 1 条：字体文件（TTF/OTF）不可单独出售。可以随软件、随作品捆绑分发，但不能把字体文件本身挂出来卖。淘宝、小红书上在售的开源字体基本都违反这一条，付的钱不会流向作者，也拿不到更新。
2. 衍生字体不能用保留名称。OFL 1.1 第 3 条：改过的字体不能沿用原字体的"保留名称"。霞鹜系列的保留名称是霞鹜（霞鶩）、落霞孤鹜（落霞孤鶩）、LXGW；思源系列的保留名称是 Source（Source 是 Adobe 的商标）。基于它们做的衍生字体，没有作者书面授权，名称里不能出现这些字样。
3. 再分发必须带授权全文。OFL 1.1 第 4 条：把字体打包分发（含嵌入、随软件发布）时，必须附带 OFL.txt 全文。字体也不能改换到 OFL 之外的其他协议下发布。

特例说明：仅为网页渲染优化做的子集化与 WOFF/WOFF2 格式转换，且不作为可安装桌面字体提供下载的，可以继续使用保留名称（Google Fonts、ZSFT 等作者认可的托管平台适用；其他平台需联系作者确认）。未改源码、直接重新编译的字体也可继续用保留名称。

三、国内使用时的两个坑

法务要"授权证明"时，OFL 会卡住。不少公司法务部门不认可开源协议的效力，要求提供传统授权证明。作者的建议是：遇到这种情况放弃使用开源字体，改用在法务上可开具证明的免费商用字体，或买商业版权字体。
手机主题商店基本走不通。国内手机品牌主题商店通常只对企业开放字体上传权限；少数允许个人上传的，要求提供版权登记证明。开源二创字体的著作权归属本身可能有争议，这条路上别硬试。

四、国内下载渠道

  • GitHub Release：各仓库 Releases 页下载 TTF，最权威，版本最新。
  • 重庆大学开源镜像站：mirrors.cqu.edu.cn/github-release/lxgw/，国内速度快，GitHub 项目更新后同步。
  • 蓝奏云（霞鹜系列，密码 8ppk）、永硕 E 盘：lxgw.ysepan.com，项目更新后 48–72 小时内更新。
  • 猫啃网、Zfont、字加：收录齐全，但版本可能落后于 GitHub，下载前对一下版本号。

五、安装

  • macOS（已装 Homebrew）：brew install font-lxgw-wenkai
  • Windows（已装 Scoop）：scoop bucket add nerd-fonts && scoop install LXGWWenKai，等宽版为 LXGWWenKaiMono
  • 网页使用：参考 LXGW Issue #24，或在 ZSFT 查找霞鹜系列网页字体
